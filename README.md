# Project Quarm Chronicle (EverQuest Log Milestone & Wrapped Generator)

A tool designed to parse multi-gigabyte EverQuest log files from the **Project Quarm** server and generate shareable milestone timelines, statistics cards, and recap summaries for characters.

---

## 🎯 Project Vision & Goals

- **Local-First Log Parsing:** Efficiently process large log files (often gigabytes in size) locally on the user's machine without requiring huge server uploads.
- **Milestone & Stat Extraction:** Identify key character moments, including:
  - Level progression and milestone dings (and NG+ resets).
  - Raid boss kills, first-time encounters, and epic quest completions.
  - Combat highlights (total damage, heals, record crits, deaths).
  - Social & community highlights (tells, friends, guild history, rivals/PvP).
  - Economic & loot highlights (money earned, iconic drops).
- **Shareable Output for Discord & Web:**
  - Visual summary cards (Discord-friendly PNG graphics).
  - Interactive web slideshow / timeline recap.
  - Optional narrative flavor text summarizing character achievements.
